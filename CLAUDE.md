# my-plugins

## Tests

```sh
cd plugins/my-agent && python3 -m unittest discover -s l4-tools-guards/tests   # L1~L4 rules and hooks
cd plugins/my-agent/monitor && python3 -m unittest discover tests            # monitor
```

There is no build step (Python standard library + static HTML). Exception: the Swift app in `plugins/my-agent/monitor/menubar/` is built with `cd plugins/my-agent/monitor && sh menubar/build.sh` (optional).

## Notes

- Write all documents, comments, prompts and messages in this repository in English. Exceptions: `README-ko.md` (the Korean README), the Korean UI strings of the monitor (`plugins/my-agent/monitor/web/index.html`, `plugins/my-agent/monitor/tools/build-web.py`), and the external reports kept in their original language (`plugins/my-agent/docs/ref/gemini-*.md`).
- Keep the core rules of `plugins/my-agent/SKILL.md` within its first 16,000 characters (about 4,000 tokens of English; `test_skill_md` checks this).
- `plugins/my-agent/maintenance-notes.md`: when you change something, add it to the matching section with the date.
- When you raise the version, change `version` in `plugins/my-agent/.claude-plugin/plugin.json` and the version in the plugin table of `README.md` and `README-ko.md` in the same commit. The three values must always match.
- `README.md` (English) and `README-ko.md` (Korean) have the same content. When you change one, change the other too (including the tool versions under requirements).
- my-agent must behave only as designed in `docs/build-guide/my-agent-architecture.md`. Do not put temporary exceptions or workaround wording into the runtime rules.
- `plugins/my-agent/monitor/web/index.html` was generated by `plugins/my-agent/monitor/tools/build-web.py` but has been edited by hand since. Running the generator again loses those edits.
- `docs/agent/` (my-agent task records) and `.superpowers/` are excluded from git.
