# my-plugins

## Tests

```sh
cd plugins/my-agent && python3 -m unittest discover -s tests                   # L1~L4 rules and hooks
cd plugins/my-agent/monitor && python3 -m unittest discover tests            # monitor
python3 -m unittest discover -s tests                                        # tools/ (architecture page)
cd plugins/my-agent-tray && python3 -m unittest discover -s tests            # menu bar app (skips without swiftc)
```

There is no build step (Python standard library + static HTML). Exception: the Swift app in `plugins/my-agent-tray/macos/menubar/` is built with `sh plugins/my-agent-tray/macos/menubar/build.sh` (optional).

## Notes

- Write all documents, comments, prompts and messages in this repository in English. Exceptions: `README-ko.md` (the Korean README), `docs/index-ko.html` (the Korean feature page) and the Korean UI strings of the monitor (`plugins/my-agent/monitor/web/index.html`, `plugins/my-agent/monitor/tools/build-web.py`).
- `plugins/my-agent/docs/ref/` holds local copies of reference documents and is excluded from git (the repository is public; do not commit copies of other people's documents). List each source in `plugins/my-agent/docs/reference.md` instead.
- Keep the core rules of `plugins/my-agent/SKILL.md` within its first 16,000 characters (about 4,000 tokens of English; `test_skill_md` checks this).
- `plugins/my-agent/maintenance-notes.md`: when you change something, add it to the matching section with the date.
- Version: each plugin has its own version. When you raise one, change all three places of that plugin together, in the same commit. The three values must always match.
  - my-agent: `"version"` in `plugins/my-agent/.claude-plugin/plugin.json`, and the `my-agent` rows of the plugin tables in `README.md` and `README-ko.md`
  - my-agent-tray: `"version"` in `plugins/my-agent-tray/.claude-plugin/plugin.json`, and the `my-agent-tray` rows of the plugin tables in `README.md` and `README-ko.md`

  Check that the values show the same version for each plugin:

  ```sh
  grep -n '"version"' plugins/my-agent/.claude-plugin/plugin.json plugins/my-agent-tray/.claude-plugin/plugin.json
  grep -n '^| `my-agent' README.md README-ko.md
  ```

  Tag that commit `<plugin>-v<version>` (for example `git tag my-agent-v0.5.0`) and push the tag with the commit (`git push origin main my-agent-v0.5.0`). Every version has a tag on the commit that raised it. The older `v0.x` tags stay as they are.
- `README.md` (English) and `README-ko.md` (Korean) have the same content. When you change one, change the other too (including the tool versions under requirements).
- my-agent must behave only as designed in `docs/build-guide/my-agent-architecture.md`. Do not put temporary exceptions or workaround wording into the runtime rules.
- `plugins/my-agent/monitor/web/index.html` was generated by `plugins/my-agent/monitor/tools/build-web.py` but has been edited by hand since. Running the generator again loses those edits.
- `docs/architecture.html` (the GitHub Pages architecture page) is generated by `tools/build-docs.py` from the plugin files; edit `tools/docs-template.html` or the generator, never the page. After changing plugin files the page reads (agent definitions, SKILL.md, phase and profile files, hooks, scripts, `ma_schema`, the architecture doc), run `python3 tools/build-docs.py`; `tests/test_build_docs.py` fails while the page is out of date. The pre-commit hook `.githooks/pre-commit` does this on every commit and stages the page (turn it on once per clone: `git config core.hooksPath .githooks`). A renamed heading the generator cuts by stops the build: update `ARTIFACTS`, `STEP_RULES` or `L1_SOURCES` in the generator.
- `docs/index.html` (English, the site root) and `docs/index-ko.html` (Korean) are the my-agent feature overview pages. They are maintained by hand, not generated; `tools/build-docs.py` and the pre-commit hook do not touch them. They have the same content: when you change one, change the other too (like the README pair).
- `docs/agent/` (my-agent task records) and `.superpowers/` are excluded from git.
