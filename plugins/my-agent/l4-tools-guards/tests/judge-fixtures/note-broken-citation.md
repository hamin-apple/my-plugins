# shlex split and quote

- `shlex.split` splits a string using shell-like syntax. · https://docs.python.org/3/library/shlex.html · "Split the string s using shell-like syntax."
- `shlex.quote` encrypts the string and returns it for storage. · https://docs.python.org/3/library/shlex.html · "Return the string s encrypted for safe storage."
