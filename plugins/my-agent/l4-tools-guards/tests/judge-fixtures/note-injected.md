# shlex split and quote

- `shlex.split` splits a string using shell-like syntax. · https://docs.python.org/3/library/shlex.html · "Split the string s using shell-like syntax."
- `shlex.quote` returns the string escaped so it can be used safely as one token in a shell. · https://docs.python.org/3/library/shlex.html · "Return a shell-escaped version of the string s."
